## COMPORTEMENT À OBTENIR

Le texte doit être un véritable élément du canvas, éditable directement sur le visuel.

Quand l’utilisateur clique sur :

« Ajouter du texte »

alors :

1. un nouveau calque texte est immédiatement créé sur le canvas ;
2. il apparaît directement sur le visuel ;
3. il est immédiatement sélectionné ;
4. il est placé à une position par défaut raisonnable ;
5. l’utilisateur peut écrire directement dans le texte sur le canvas ;
6. il peut déplacer le texte ;
7. il peut modifier ses propriétés avec les contrôles existants ;
8. il peut cliquer sur « Valider » pour terminer l’édition ;
9. le texte reste ensuite présent comme un calque normal ;
10. l’utilisateur peut cliquer à nouveau sur « Ajouter du texte » pour créer un deuxième texte indépendant.
